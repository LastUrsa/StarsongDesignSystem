# TuberSwitch

## Purpose
TuberSwitch is the Starsong application focused on avatar and mode switching workflows, especially for VTuber and stream scene management.

## Core Features
- mode switching
- OBS scene and source configuration
- reward mapping
- app detection
- Twitch integration support

## Current State
TuberSwitch is the most compact and utility-oriented Starsong application today. It provides strong examples for topbar shells, compact status presentation, and straightforward settings organization.

## Future Opportunities
- broader named profile support
- SIP adoption
- Starsong Profile participation beyond built-in modes
- ecosystem status and orchestration integration

## SIP Opportunities
TuberSwitch already has concepts that fit SIP well:

- identity
- health
- status
- actions
- partial profile foundations through `ModeProfiles`
