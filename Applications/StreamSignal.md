# StreamSignal

## Purpose
StreamSignal is the Starsong application focused on multi-destination stream announcements and related publishing workflows.

## Core Features
- destination management
- destination groups
- announcement profiles
- preview generation
- workflow execution for go-live and end-stream cases
- logs and recovery support

## Current State
StreamSignal is currently the most mature Starsong application from an ecosystem-pattern perspective. It already contains strong shell, settings, card, and profile patterns that influenced the Starsong Design System v1.1.

## Future Opportunities
- SIP adoption
- ecosystem-aware profile activation
- shared orchestration participation
- improved ecosystem status reporting

## SIP Opportunities
StreamSignal is a strong candidate for early SIP adoption because it already has:

- a meaningful identity model
- health and status concepts
- actions that map well to lightweight interoperability
- a real named profile system
