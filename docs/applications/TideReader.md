# TideReader

## Purpose
TideReader is the Starsong application focused on music detection, now-playing workflows, and customizable overlay output.

## Core Features
- now-playing detection
- overlay rendering
- overlay appearance customization
- browser and metadata support configuration
- local overlay serving

## Current State
TideReader has the richest settings and styling editor in the current ecosystem. It is especially valuable as a reference for form behavior, validation patterns, and preview-driven configuration workflows.

## Future Opportunities
- named overlay profiles
- SIP adoption
- Starsong Profile participation
- richer ecosystem metadata and status integration

## SIP Opportunities
TideReader is a strong SIP participant for:

- identity
- health
- status
- actions

It will likely need a clearer application-profile abstraction before full Profiles v1 participation.
