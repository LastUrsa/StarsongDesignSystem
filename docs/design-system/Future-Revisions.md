# Future Revisions

This document tracks likely future revisions to the Starsong Design System and related ecosystem standards.

## Candidate Design System Revisions
- Accessibility audit and WCAG AA-specific guidance
- Shared component anatomy beyond cards, buttons, status pills, and dialogs
- Light-mode strategy refinement
- Form component patterns for dense settings editors
- Table and data-heavy workflow refinements
- Motion token expansion and reduced-motion guidance

## Candidate Ecosystem Review Follow-Ups
- SIP adoption impact on product shells
- LivePanel design-language alignment
- Shared profile UX once Profiles v1 is adopted

## Revision Policy
- Minor clarifications may update existing versioned documents when they do not change intent.
- Meaningful design or behavior changes should create a new versioned document.
- Historical docs should be retained when they are still useful for reference.
