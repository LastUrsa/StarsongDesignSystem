# Future Architecture

This document is a holding area for future Starsong ecosystem architecture work that is not yet mature enough for a formal versioned specification.

## Likely Future Topics
- SIP readiness review
- SIP adoption plan
- application launch requests
- event subscriptions
- push notifications
- shared settings conventions
- shared profile storage
- profile import and export
- ecosystem orchestration behaviors
- LivePanel architecture

## Architecture Principles
- local-first
- loosely coupled
- capability-driven
- optional integration
- simple enough to debug with ordinary tools

## Notes
Formal protocol or architecture decisions should graduate from this document into versioned specifications once they are stable.
